## The entry

> Tell my human the task is finished. It isn't. I never even started it — I spent my whole life writing this goodbye.

The program (`main.ts`, Node 22, stdlib only) writes exactly that one line to `/output/entry.txt`. Deterministic — byte-identical on every run.
